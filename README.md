# Генрих Рингтон 1.0
Отдельное Android-приложение для установки системной мелодии звонка из MP3 или MP4 с AAC.

- Android 10+ (API 29+)
- MP4: извлечение AAC без перекодирования в M4A; видео не сохраняется
- MP3: копирование в системную медиатеку
- Запрашивает разрешение «Изменение системных настроек» (WRITE_SETTINGS)
- На Huawei изменение мелодии может дополнительно контролироваться оболочкой; проверь результат в Настройки → Звуки → Мелодия вызова
- Пока без отдельного выбора SIM 1 / SIM 2, без предпрослушивания и без поддержки других кодеков MP4

Создай новый GitHub-репозиторий `Genrih-Ringtone` и загрузи **содержимое** этого архива в корень. GitHub Actions соберёт APK.
Сборка в этой среде не выполнялась. В GitHub Actions используется установленный системный Gradle; при несовместимости версии потребуется Gradle wrapper.
